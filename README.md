# Getting Started

This repository contains multiple independent projects.

Clone the repository:

```bash
git clone https://github.com/plausibleCoder/omnistack.git
```

Then navigate to the project you are interested in:

```bash
cd omnistack
```

Each project may use different technologies and setup requirements.

For example:

### Java / Spring Projects

```bash
cd <project-folder>
./mvnw spring-boot:run
```

### Node.js / Frontend Projects

```bash
cd <project-folder>
npm install
npm run dev
```

### Python Projects

```bash
cd <project-folder>
pip install -r requirements.txt
python <application-file>
```

Refer to individual project files and documentation for project-specific configuration.

# Why Omnistack?

Modern software engineering requires more than expertise in a single language or framework.

A typical application may involve:

```text
Frontend
   ↓
REST APIs
   ↓
Backend Services
   ↓
Databases
   ↓
Cloud Infrastructure
```

Increasingly, modern systems may also include:

```text
                AI / LLM
                    │
                    ▼
Frontend ───► Application Layer ───► External Services
                    │
                    ▼
                 Data Layer
                    │
                    ▼
                   Cloud
```

Omnistack is my workspace for exploring these layers and understanding how they fit together.
